# Attribution and conditions

Reasonance wrote this released-data adapter and identifier audit. It transforms
numeric CSV rows into an analysis-only database, filters the headline roster,
and adds exploratory identifier-count summaries. It also presents selected
aggregate evidence and methods from a completed independent released-data
confirmation in `confirmed-evidence.json`. **The reconstructed database is not
the authors' original database.** No original code or full data tables are vendored.
